# ERRATA resource pack

**ERRATA** offers this optional pack to Minecraft Java 1.21.11 on your first join after login. Accept the in-game prompt
to use it that session. Flashlight beams, encounters, and paging also run on stock clients.

What it adds:
- articulated animated creatures and archival wildlife, including Cave Dweller variants retaining the face and clothes of their former Reader
- subtle found-footage grain and vignette for Java while the server supplies directional block lighting
- district ambience, overlapping soundscapes, music, and recorded intercom cues
- custom item art for the flashlight, shortwave radio, resonator, grounding strap, glassroot spore, erratum sheets, survey compass, chalk, thread, handbell, flares, and bell key
